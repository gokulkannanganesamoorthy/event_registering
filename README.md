# event_registering

> **EventSphere** — A premium event registration and discovery platform.

A world-class event platform built with **React + Vite + Tailwind CSS**.  
Discover extraordinary events near you, or post your own.

---

## Tech Stack

- **React** + **Vite** (v8)
- **Tailwind CSS** v3
- **Framer Motion** — animations & transitions
- **React Router DOM** — client-side routing
- **React Helmet Async** — dynamic SEO meta tags
- **Lenis** — smooth scrolling

---

## Pages

| Route | Page |
|-------|------|
| `/` | Home — Hero, Stats, Event Grid, How It Works, Host CTA, Testimonials |
| `/events` | Browse all events with search + filters |
| `/post-event` | 3-step event creation form |
| `/about` | Mission, values, team |

---

## Getting Started

```bash
npm install
npm run dev     # → http://localhost:5173
npm run build   # production build
```
